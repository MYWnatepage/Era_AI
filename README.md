# 测试版本V 1.0 · 历史清理版

此版本保留 2026 年 6 月 30 日最初的「测试版本V 1.0」代码与旧运行器，便于与当前 Era AI 0.2.x 分别查看、下载。

原始代码来自提交 `6ef9a0baeabad110c25cc50929b581fbd9804eec`。

## 清理范围

本历史副本移除了当时的 `global.sav`、`setting.json`、`emuera.config`。不包含个人存档、使用配置、API 密钥或运行缓存；不导入这些旧数据。旧代码和运行器未做功能升级，另补充本说明及上游许可。

## 使用范围

这是早期 Python AI Bridge 实验版本，环境与启动方式沿用旧版本。请放在独立文件夹中，自行配置 Python、服务连接与所需的旧运行环境；入口为 `start_game_ascii.cmd`。该历史包没有通过本次 0.2.x 的功能测试，也不是当前自带运行环境的玩家包。

当前维护版本见 https://github.com/MYWnatepage/Era_AI/releases/tag/v0.2.1-alpha 。旧版名称中的「1.0」沿用早期命名，不代表比 0.2.x 更新或更稳定。

Era AI 基于 Emuera；旧运行器与依赖版权归各自作者，许可原文保留在 `许可/` 中。
