# 游戏说明

Era_AI 是一款 AI 文字冒险游戏，通过对话和选择推进故事。具体世界观、人物与玩法由所选剧本决定。

## 首次使用

1. 打开“设置 → 模型连接设置”，选择网络 API 和服务地址。
2. 填写 API 密钥，读取模型列表并选择模型，再测试当前连接。
3. 返回主菜单，选择“开始新游戏”及剧本；已有进度可选择“读取存档”。

## 基本操作

- **选择选项**：点击带编号的选项，或输入编号后按 Enter。
- **返回与取消**：有上级的页面按 Esc 返回；输入文字或数值时，按 Esc 取消本次输入。
- **编号说明**：各页以实际标注为准；数字 0 通常用于返回，主菜单的数字 0 是开始新游戏。
- **查看长页面**：使用鼠标滚轮查看上方内容；在输入栏按 PageUp / PageDown 翻阅。

## 保存与消耗

- **保存进度**：在剧本操作页手动保存，也可在设置中开启自动存档；重要节点建议手动保存。
- **等待回应**：需要中止请求时按 Esc；已执行的行动如何结算，以当前剧本规则为准。
- **用量与音乐**：右上角图表查看本游戏近7日消耗，喇叭控制音乐；连接测试也可能产生调用费用。

## 在游戏内查看

主菜单选择“游戏说明”后，首先显示上述内容。选择 [1] 可切换到“运行环境与接入要求”，再次选择 [1] 返回使用说明；两页均可输入 [0] 或按 Esc 返回标题。

运行环境与接入要求沿用原有内容。本地大模型仍标注为“未完成”。
