# 地图原生化与资源测量

日期：2026-10-25。

地图现在由 C# 与 Windows OpenGL/WGL 原生绘制。发布版不再启动 WebView2，不执行网页或 JavaScript；原网页代码保留为迁移对照，未嵌入发布程序。

## 测量方式

- 在同一台电脑、相同的 1280×720 原生游戏窗口、同一个艾拉剧本初始场景下比较。
- 使用真实游戏引擎的隔离测试目录，不读取玩家 API 密钥，不请求 AI，不覆盖个人存档。
- 记录标题和行动菜单就绪后的基线，再记录地图首次完成绘制后约 250 毫秒的值。
- 主指标为整个测试宿主及其后代进程的 Private Bytes（专用提交内存）；网页版本的浏览器、渲染和 GPU 子进程一并计入。
- 单位 MiB = 1,048,576 字节。该指标不等同于物理内存或显存，也不是地图模型文件大小。

## 同场景结果

| 项目 | 原网页版本 | 原生三维版本 |
|---|---:|---:|
| 打开地图前的专用内存 | 57.5 MiB | 57.1 MiB |
| 打开地图后的专用内存合计 | 331.5 MiB | 155.8 MiB |
| 地图打开带来的增量 | 274.0 MiB | 98.6 MiB |
| 进程数量（测试宿主及后代） | 7 | 1 |

本轮增量下降约 64%。不同轮次、驱动缓存和窗口大小会影响结果；先前原生轮次曾测到约 65 MiB 的增量，因此这些数值是本机实测样本，不是所有电脑的固定占用。

连续十二次开关后，确认原生绘图上下文计数为零、清理失败计数为零，控件已销毁。进程专用内存仍有保留，最后采样约 218.2 MiB；关闭地图不保证整个运行时和显卡驱动立刻归还所有内存。该压力测试含截图、长文本和多种配色操作，不能将该值直接当作地图模型常驻大小。

## 保留的能力

地形高度场、建筑树林与溪流道路来自同一份剧本地图布局。原生几何与原网页版本对照：7,192 个地形三角形、628 个建筑树林等实体三角形、440 个溪流三角形、222 个道路三角形，以及相同的高度采样与网格分割。

旋转缩放、地点悬停与选择、坐标、指南针、示意比例尺、当前位置与目的地、固定 7:3 布局、长介绍滚动、主题配色及返回操作都经过实际游戏测试。地图仍仅接收本局资料的副本，浏览不写游戏状态。

新增地点、地形与装饰继续通过地图资料和存档扩展。右键贴地绘制、左键确认及右键清除路线已实装。测量时实际沿路线移动尚未接入；后续0.3.0已接入按距离消耗行动点和保存实际位置，当前操作见根目录《使用说明.md》。本页内存数据仍是2026-10-25的测量样本。

## 发布与维护

地图使用 Windows 的 OpenGL 接口，不增加三维引擎或浏览器安装包。显卡驱动需要支持 OpenGL 2.1 或以上；初始化失败时使用现有兼容地图。

游戏主体仍以自带 .NET 运行环境的单文件形式发布，所以移除网页组件后，程序体积只会减少相应组件的部分，不会变成几 MB 的程序。
