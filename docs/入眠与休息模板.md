# 入眠与休息固定模板

入眠与休息使用本地固定文本，不调用AI。地点占位符由当前地点替换，正文按已完成回合进度轮换；同一进度预览、重试和读档选择一致。既有恢复、耗时和食材规则保持不变。

## 入眠正文

1. 你在{地点}安顿下来，暂且放下手边的事情，慢慢进入梦乡。
2. 你在{地点}收拢心绪，把注意力从眼前的事情上移开。过了一阵，你睡着了。
3. 你在{地点}准备入眠，不再继续考虑接下来的安排，渐渐睡去。
4. 你在{地点}停下今天的活动，安静地待了一会儿，随后进入睡眠。
5. 你在{地点}安静下来，思绪渐渐放缓，在不知不觉中睡着了。
6. 你在{地点}把接下来的事情暂放一旁，让这一段时间在睡眠中度过。

## 休息正文

1. 你在{地点}暂时停下活动，放缓节奏，给自己留出片刻喘息的时间。
2. 你在{地点}歇了一会儿，没有急着继续行动，只让这段时间慢慢过去。
3. 你在{地点}安静地休息片刻，把注意力从眼前的事务上移开。
4. 你在{地点}暂停了手边的事情。等这段休息结束，再考虑接下来的安排。
5. 你在{地点}稍作停留，整理了一下思绪，没有立刻开始新的行动。
6. 你在{地点}给自己留出一小段空当，暂且不赶路，也不忙着做别的事。

## 人物在场说明

正文后按实际情况追加一句，不安排其他人物入眠或采取行动。

- 独处：这段时间，你独自休息。
- 有其他已登记人物在场：这里还有{人物}。多人姓名用顿号连接。

## 地点加成追加句

1. 这里的环境让你能更从容地休息。
2. 在这里休息，比平常更容易放松一些。
3. 此处的条件让这段休息更加充分。

## 入眠后的场景近况

1. 你在{地点}睡过一觉，仍停留在这里。
2. 这次睡眠已经结束，你还在{地点}。
3. 你在{地点}结束了这次睡眠，尚未离开。

## 休息后的场景近况

1. 你在{地点}歇了片刻，暂时没有开始新的行动。
2. 这段短暂的休息已经结束，你仍停留在{地点}。
3. 你在{地点}给自己留出了一段休息时间。

地点加成句仅在实际规则给予额外恢复时追加；正文与近况不宣称伤病痊愈，也不预设天气、家具或装备。
