# 框架页面文件结构

主菜单、设置、游戏说明和关于属于框架。它们可以共享通用函数，但不依赖某个具体剧本。2026-10-22按职责拆分文件，原有函数名、参数、菜单编号、显示文字、调用顺序与保存逻辑保持不变。

## ERB第一层

| 文件 | 职责 |
| --- | --- |
| SYSTEM_TITLE.ERB | 主菜单跳转、退出确认 |
| SYSTEM_SETTINGS.ERB | 设置首页、自动存档和返回确认开关、设置摘要排版 |
| SYSTEM_DISPLAY.ERB | 颜色、字体、字号、行距、窗口大小，以及公共显示初始化和辅助函数 |
| SYSTEM_MODEL.ERB | 模型连接、服务地址、密钥、模型列表、连接测试、账户用量页面与教程 |
| SYSTEM_HELP.ERB | 框架通用游戏说明 |
| SYSTEM_ABOUT.ERB | 项目介绍、版本、作者和运行器致谢 |
| SYSTEM_GENERATION.ERB | 采样、回复长度、上下文管理、思考模式及相关辅助函数 |
| SYSTEM_MUSIC.ERB | 背景音乐与内置曲目选择入口；音量编辑器由运行器提供 |
| SYSTEM_MAIN.ERB | 通用新游戏、剧本选择、生命周期调用、自动保存与存档说明 |
| SYSTEM_SCENARIO_LOAD.ERB | 按剧本读取存档、旧档识别与恢复入口 |
| SYSTEM_TURNEND.ERB | 把回合结束事件交给当前剧本处理 |
| 历史记忆.ERB | 通用历史摘要管理：手动添加、从对话摘录、确认AI建议、编辑、置顶、失效和删除；由剧本显式调用 |

`SYSTEM_TITLE.ERB` 从约一千行缩减到约一百行。页面之间继续使用原有CALL关系，引擎会统一加载ERB第一层的文件，无需手动添加加载顺序。

## 维护时放在哪里

- 增加或调整设置首页条目：修改SYSTEM_SETTINGS.ERB，并调用对应设置文件中的函数。
- 修改配色、窗口和字体界面：修改SYSTEM_DISPLAY.ERB。
- 修改模型连接或教程：修改SYSTEM_MODEL.ERB；生成参数页面修改SYSTEM_GENERATION.ERB。
- 修改通用游戏说明：修改SYSTEM_HELP.ERB。
- 修改项目介绍与致谢：修改SYSTEM_ABOUT.ERB；项目名称、作者、版本等元数据仍在CSV/GameBase.csv。
- 修改某个剧本的故事、人物、初始物品、行动或结局：只修改script下对应剧本包，接入约定见[剧本接入](剧本接入.md)。

公共的APPLY_DISPLAY_SETTINGS、INIT_DISPLAY_SETTINGS、EDIT_DISPLAY_COLOR等函数位于SYSTEM_DISPLAY.ERB，其他框架页面和剧本都可以调用。INIT_DISPLAY_SETTINGS保留旧版通用开关初始化的兼容逻辑，本次只移动文件，不改变其行为。

## 验证与运行

拆分时逐个比对了32个原有函数，函数实现保持一致，没有遗漏或重复定义。针对原文件位置编写的测试，已改为定位相应的新文件，原有检查内容保留。

使用`测试.ps1 -Engine`验证现有页面和剧本。ERB脚本拆分无需重新构建EraAI.exe；关闭并重新打开游戏后加载新的文件结构。
