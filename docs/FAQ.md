# 常见问题

## 下载哪个文件？

前往 [0.2.1 Alpha 发布页](https://github.com/MYWnatepage/Era_AI/releases/tag/v0.2.1-alpha)，下载 `Era-AI-v0.2.1-alpha-win-x64.zip`。完整解压后运行 `EraAI.exe`。GitHub 自动生成的 Source code 是开发源码，需要自行构建。

## 需要安装 Python 或 .NET 吗？

当前 Windows x64 玩家包自带运行环境，不需要。源码构建需要 .NET 10 SDK；只有引擎集成测试另外需要 Python 3。历史 Python Bridge 版本的环境要求不同。

## 填完密钥为什么还不能对话？

按「网络 API → 服务地址 → 完整密钥 → 读取并选择模型 → 测试连接」检查。确认所选服务与密钥相配，并查看具体错误。不要将完整密钥、带密钥参数的地址或配置文件发到公开 Issue。

## 哪些操作会产生费用？

连接测试和游戏中的 AI 生成请求可能产生 Token 消耗。读取模型列表及已适配的余额查询不生成角色回复。具体计费与接口限制以所选服务为准。

## 本地模型现在能用吗？

当前游戏入口标记为未完成，不作为已实现功能提供。

## 为什么模型容量显示未获取？

部分服务的模型列表不返回容量，或者缓存需要刷新。未获取容量不代表模型不能使用；可以在模型连接和生成设置页面查看、刷新，按实际服务限制配置。

## Token 预算是不是一定会用完？

手动预算是上限，实际可能更少；自动预算沿用服务默认行为，不保证低消耗。回复长度是文字表达目标，与 Token 预算分别设置。

## 换电脑后为什么密钥不能用了？

密钥通过 Windows DPAPI 保护，换电脑或 Windows 账户后需要重新填写。不要公开分享包含加密密钥的配置。

## 升级如何保留进度？

先保存自己的配置、数据和存档副本，再将新版解压到另一目录，检查版本说明中的兼容性后迁移。不要直接覆盖整份游玩目录。历史快照缺失的旧存档不能恢复当时未保存的独立对话。

## IDE 为什么只显示旧提交？

先确认打开的本地仓库和远端地址，再执行 Fetch，查看对应远端分支。别处推送成功，不会自动刷新每个本地仓库。Fetch 与 Pull 不同，不会把远端文件合并到当前工作目录。
