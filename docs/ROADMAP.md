# 开发路线图

当前项目版本为0.3.0。本页汇总仍需跟进的工作，更新于2026-10-27；已经完成的改动见根目录《更新记录.md》，具体操作见《使用说明.md》。计划不承诺完成日期。

## 已有基础

- 网络API、模型和生成设置、用量统计、音乐及可调速剧情显示。
- 独立剧本资料、初始人物与物品、本局库存、人物持续状态和动态人物登记。
- 原生三维地图、贴地路线移动、地点行动与增益、行动点、疲劳和骰子判定。
- 历史对话、长期记忆与存档恢复；按当前行动筛选交给AI的资料。
- 核心模拟测试和隔离剧本测试；日常沿用 `master` 与 `test`，分支由维护者手动管理。

## 玩法与结果一致性

- 完善交易、价格、付款收货关联与自动找零，减少需要人工确认的物品提案。
- 为装备、弹药、物品使用和其他行动补充明确规则及耗时。
- 建立任务和事件进度的校验，减少重复触发及叙事与本局数据不一致。
- 连续试玩检验食材、狩猎收益、移动消耗、疲劳与休息的节奏。

## 长流程与体验

- 继续改进人物表现、剧情连贯性、长期记忆摘要和相关信息召回。
- 改进上下文预算估算与兼容性，不将当前估算当作模型精确分词结果。
- 优化余额查询等待、存档分页、大量物品浏览及连接失败反馈。
- 按需要适配更多平台的账户查询和费用估算。
- 持续检查旧存档迁移、内存占用、界面和不同显卡环境的表现。
- 发布前核对源码与程序对应关系，执行隐私清理、界面及运行包检查。

## 后续扩展

- 本地大模型接入。
- 流式回复。
- 根据剧情生成场景、人物或物品图片。
- 更多剧本和内容。

涉及存档或请求格式的修改，先明确兼容与恢复方式，再实现和验证。依赖版本升级按需安排，不由常规自动升级任务创建分支。
