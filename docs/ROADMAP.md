# 开发路线图

当前版本为 0.2.1 Alpha。以下是工作方向，不是已实现功能或完成时间承诺；具体任务和进展以仓库 Issues 与 Milestones 为准。

## 近期：0.2.x 稳定性与维护

- 建立可持续运行的 Windows 构建、核心模拟测试和发布检查。
- 改进连接失败、参数支持、上下文预算和存档迁移的反馈。
- 扩充兼容性记录，核对打包依赖和许可声明。
- 补充清晰的使用示例与问题复现资料。

## 后续：剧本与表现能力

- 用 ERB 组织人物、物品、场景资料，按需加载。
- 明确 AI 文字表达与游戏状态变更之间的边界，完善事件结果校验。
- 验证背景、立绘、音乐和音效，以及读档后的恢复行为。
- 改进长流程的历史管理、资料选择和上下文组织。

## 待设计

- 本地模型接入。
- 流式输出。
- 更完整的卡片和资料检索体系。

涉及存档或请求格式的设计，先说明兼容方案再实现；不为了赶版本号打包尚未验证的功能。
