# 掷骰动画

游戏目前只启用 D20 动画，不提供玩家骰子选择、自定义点数或重新投掷入口。D4、D6、D8、D10、D12、D20 的几何模型一并保留在源码，供后续开发使用。

## 行为

程序行动先确定骰点，随后将同一个结果发送给 AI，并交给动画展示。开始快速旋转、轻微弹跳，等待 AI 时保持较慢的持续转动；收到完整回复或请求失败、取消、超时后，约 0.7 秒停稳，再高亮原点数约 0.9 秒，随后显示剧情或原有简短结算。即使服务立即返回，也保留停稳和结果展示。

等待期间可按 Esc 或点击中止请求，仍按原程序规则完成本次行动。喇叭按钮可继续使用；动画不会开放消耗图表或接受新的行动输入。调整窗口大小时按当前区域重新绘制。关闭游戏时释放动画计时器。

## 文件职责

| 文件 | 职责 |
| --- | --- |
| 源码/Emuera/NativeDisplay/DiceGeometry.cs | 六种骰子的顶点、多边形面、编号和停稳方向；没有物品、角色或剧本规则 |
| 源码/Emuera/NativeDisplay/D20Animation.cs | D20 旋转、等待、停稳、结果展示和主题绘制；不生成随机数，不修改存档 |
| 源码/Emuera/UI/Framework/Forms/MainWindow.Dice.cs | 窗口重绘计时器、输入保护、Esc 中止与资源释放 |
| 源码/Emuera/NativeAI/AiRuntime.cs | 将当前已确定的 D20 行动结果交给展示层，普通对话不触发 |
| 源码/Emuera/Runtime/Script/Statements/Instruction.NativeAI.cs | AI 请求与动画生命周期衔接，结果展示完毕后放行同一份回复 |
| 游戏/ERB/script/艾拉的奇幻冒险/ | 继续拥有骰点、收获、物品、时间与失败后的结算规则 |
| docs/设计预览/掷骰动画.html | 独立设计预览，保留多种骰子供作者查看，不是游戏菜单或运行依赖 |

动画不按自然语言猜测判定，不额外请求 AI，也不增加发送给模型的提示词。普通对话、模型连接测试和不含 D20 判定的行动保持原流程。

## 验证

`DiceAnimationTests` 覆盖几何面数、编号、相对面、20 个结果、长时间等待、停稳方向、重复完成、取消与失败、深浅主题和窗口尺寸。真实窗口测试检查输入保护、消耗图表阻挡、Esc 与计时器释放；狩猎引擎测试覆盖成功、失败、取消、无效操作和存档，确认不会重复掷骰或发放收获。
